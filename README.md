# 远山

一款关于慢下来、探索山谷、照顾动物与布置木屋的治愈系生活模拟游戏。

## 运行

使用 Godot 4.7 或更高版本导入 `project.godot`，然后按 `F6` 运行主场景。

## 操作

- 方向键：移动
- Enter：抚摸小满
- Tab：打开或关闭背包
- F9：保存游戏
- F10：读取存档

游戏关闭时也会自动保存。存档包含玩家位置、日期时间、天气、背包和已采集物品。

## 当前内容

- 可探索的第一张山谷地图
- 平滑跟随摄像机
- 小木屋
- 会散步和跟随玩家的猫“小满”
- 昼夜时间与晴雨天气
- 野莓采集与背包
- 保存和读取进度
